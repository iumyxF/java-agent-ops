## Mandatory Rules

The following rules must be observed:

1. Coding shall follow the KISS principle: keep code simple, straightforward and readable; avoid unnecessary abstraction
   and over‑engineering.
2. All methods except getter/setter methods must be documented with Javadoc comments. The comments shall include method
   description, parameter descriptions, return‑value description and exception descriptions.
3. Every newly‑added Java file must contain a file‑level comment. The comment shall include: fixed author value `iumyx`,
   class description (`description`), and file creation date (`date`) in the format `yyyy‑MM‑dd HH:mm`.
4. Sensitive information must not be printed in logs.
5. Ambiguous naming is prohibited.
6. Code shall remain clean, compilable and maintainable.
